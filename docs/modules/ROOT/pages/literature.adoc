= Literature
:description: Authoritative conversation sources behind published HCI Nerdz concepts.

Some encyclopedia topics began as research conversations (exports, design dumps).
Those raw sources live in the docs repository under `literature/` so agents and maintainers can re-check claims against the original thread.

They are *not* polished docs.
Prefer the curated topic pages for teaching; open the literature files when you need provenance, wording history, or unused side-paths from the conversation.
