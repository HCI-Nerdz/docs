A *conversation canvas* puts agent chats on a desk instead of a single scrolling list.
Each chat is a card: a picture of the conversation, a short clipped blurb, and an optional status lamp beside History.
You move the cards. The transcript stays closed until you open one.

== Core claim

A harness inbox is project management.
Agent working, needs-you, unread, read, error, draft, and signed-off are different jobs.
A checkmark is not enough, and "the agent stopped" is not the same as "I reviewed it and signed off."

== Cards

* *Preview* — a picture of the conversation, so you recognize it before you read the words.
* *Blurb* — one or two clipped lines under the picture.
* *Status lamp* — beside History on the card footer; color encodes the states below. No lamp after sign-off.
* *Position* — you place the card. The desk remembers.

Only cards inside the viewport are mounted.
A card is a shell: title, status, blurb, position.
The full transcript loads when you open the chat.

== Statuses

[cols="1,1,2"]
|===
| Lamp | Color | Meaning

| Agent working
| Green
| The agent is running or background work is still live.

| Needs your response
| Yellow
| Waiting on your review or reply (including planning-mode style waits).

| Unread
| Blue
| New activity since you last opened the thread.

| Read
| Grey
| You saw the latest; not signed off.

| Unsent draft
| Grey
| You have unsubmitted text in the composer (first prompt or any reply).

| Draft while needs-you
| Half yellow / half grey
| Unsent reply on a thread that already needs you (vertical split on the lamp).

| Stopped on error
| Red
| The agent run halted on an error.

| Paused
| Slate
| Parked until an external event (CI, timer) — not the same as yellow needs-you.

| Signed off
| (none)
| You reviewed and marked done. No lamp on the card.
|===

== Archive bin

Archiving takes a card off the desk.
The bin remembers the card's place.
Opening the bin offers three views:

* *Spatial* — cards return to their remembered spots, stacked by how recently they were archived.
* *Grid* — chronological thumbnails.
* *List* — compact rows.

Restore puts the card back on the desk at the remembered place and raises it above the cards already there.

== Files and topic history

Drop a file from Explorer onto the desk.
Drag a connection from that file to the chat that should start from it — for example a markdown copy of an earlier chat used as the next prompt.

When the title changes, the previous title becomes a bookmark.
Bookmarks are newest-first under *History* on the card.

== Demo and product

The public demo at https://hci-nerdz.github.io/conversation-canvas/ is a static prototype.
The shipped product would load real transcripts, provider status, and OS-window chat on desktop.
