== Contrast check

facto-stack v0.4.0 runs the chassis contrast check by default after each build. It fails on WCAG AA errors in dark mode and in dynamic states. The hub does not override or disable it.

== Brand CSS fixes

* Each hub `--adt-*` variable now has a `--valentus-*` alias, so Valentus 4 picks up the hub palette. Before this, Valentus 4 ignored most of the hub brand in light mode.
* Light `--hci-ink-muted` is `#4b5563` and `--hci-honesty` is `#0b625c` (AA on the paper background).
* Search results, highlight.js section titles and page-context panels get dark-mode colors. The search input gets a visible dark focus ring.

== Follow-ups

* Valentus/page-context dark defaults are below AA. The hub overrides them for now; they should be fixed upstream.
* 112 light-mode static findings are still reported only. They are outside the default fail scope.
