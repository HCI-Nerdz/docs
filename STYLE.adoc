== Pull request titles and summaries

PR *titles* use simple plain language; PR *summaries* use inviting plain English (lead with the human problem; screenshots for UI-visible changes). See the full site STYLE and link:https://github.com/dev-centr/agent-rules/blob/main/general/pull-requests.md[dev-centr/agent-rules pull-requests guide].
