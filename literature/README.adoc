Do not treat this folder as polished documentation.

== Adding a source

. Put the export under `literature/<concept>/` with a stable kebab-case filename.
. Add a row to the catalog above.
. Link the curated docs topic (and essay when one exists) under a *Literature* / *Source* section.
. Prefer *move* from Downloads once the repo copy is the authority.
