## Intent (paraphrased)

GitHub CLI `gh --attach` (≈ 2026-09) replaces the hacky `.issues` → `raw.githubusercontent.com` image CDN workflow for live forge filings. Consumer still wants durable backups of submissions. Broader thesis:

1. Future AI interaction with remote structured collections centers on provider-native fuzzy → vector/graph search so agents need not keep full local replicas for RAG.
2. Consumers will want opt-in redundant backups via providers that **mimic the source data structure and API surface**.
3. Privacy/portability law pressure + building demos that show benefits of open consumer access vs locked host-only data.
4. Near-term demo wedge: `.issues` archive + Issues Browser; skills updated for `--attach` + keep local media.
